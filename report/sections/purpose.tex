\section{Purpose}
\label{sec:purpose}

This note documents the code and the parameter values behind the figures
listed in \path{Figuras_papers.pdf}: Figures 1.4, 1.5, 1.6, 1.9, 1.B.3, and
1.F.1 of the bipolar model, Figure 6 of the main paper (``Equilibrium Trade
Regimes: Power- vs. Rules-Based,'' CEPR DP 20751), which uses the two-leader
variant of the bipolar model, and Figure 2.1 of the multipolar model, which is
Figure 1 of the Papers and Proceedings (P\&P) paper. \Cref{tab:map} maps each figure to the script that computes it, the
data file it reads, and the image it produces. All files sit in the folder
\code{figures\_code}; the \code{README.md} there explains how to run them.

The bipolar figures are equilibrium maps: for every point of a grid of
parameter values, a MATLAB script solves the model, records the symmetric
Markov equilibrium, and saves the result to a \code{.mat} file. A separate
plotting function draws the maps from the saved files, and two short Python
scripts add labels and assemble panels. The multipolar figure plots
closed-form expressions in Python and needs no solver.
